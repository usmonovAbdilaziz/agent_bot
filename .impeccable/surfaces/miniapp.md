# Taklif Mini App
Mode: Operate. Sender creation happens in Telegram chat; receiver and sender preview use the same rendering.

Two types: seven fun designs show Ha/Yo‘q; five ceremony designs show event cards, map/calendar and RSVP. Ceremony creation is controlled by ENABLE_CEREMONY (default off); existing links continue to work. Open ceremony links support multiple guests; personal links bind one. `/guests` is sender-only in the bot.

Optional photo, MP4 or video note fills the background beneath scrim and contrast panel; no circular-media layout applies. No media uses a local gradient. Text position is top, center or bottom. Controls are at least 48px, user content is text, focus is visible, and reduced motion disables effects. Verify loading, retry, preview, ready, accepted/answered and closed-event states at mobile and desktop sizes.
