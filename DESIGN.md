# Minimal taklif

Telegram native theme, system sans-serif. Content width <=480px, padding 24px
(16px on narrow screens), full-viewport optional background media, title 28px/25px,
body 16px. Fun uses media, title, description and Ha/Yo‘q; ceremony uses event cards, map/calendar and RSVP.
No sender form or chat controls in the receiver page.

No media uses a local design gradient; a dark scrim and opaque text panel keep text legible over all media. Text position is top, center or bottom, with bottom as default. Long text scrolls inside its panel. Videos play muted inline with an explicit sound
button. Preview shares the exact rendering, disables acceptance and explains returning
to the bot. Yo‘q remains in its arena and cannot overlap Ha. Every ten attempts shows
a temporary 😡 without a modal or extra dismiss step. Pointer and keyboard supported.

Each no attempt enlarges Ha within its arena. Design registry thresholds control
phrases, the temporary sticker and a stronger reaction. Server-confirmed Ha shows
the chosen design's local celebration and thanks, then closes the Mini App.
Reduced motion skips celebration and shaking. Error states allow retry.
Telegram's native close always remains available. Long text wraps, focus is visible,
controls have minimum 48px hit targets. Success is never shown on a failed request.

Ceremony creation is gated by ENABLE_CEREMONY (default off); published invitations remain accessible. Open links can be shared with multiple guests, personal links bind one. `/guests` is sender-only. Five ceremony designs use the same M1 contrast panel and RSVP; fun has seven designs. All media, including video notes, is a full-screen background; no circular-media display rule applies.
